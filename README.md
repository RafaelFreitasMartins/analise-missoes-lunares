# analise-missoes-lunares




Este dashboard apresenta uma análise de **166 missões lunares**, mostrando os principais operadores, tipos de missão e resultados.

Os **Estados Unidos, principalmente a NASA**, lideram com 61 missões, seguidos pela União Soviética. O tipo de missão mais comum foi **Orbiter**, com 59 registros.

Das 166 missões analisadas, **78 foram bem-sucedidas**, representando aproximadamente **47%**. Também podemos observar que houve um grande número de missões durante a corrida espacial e um novo crescimento nos últimos anos, de forma geral, o dashboard ajuda a entender **quem realizou as missões, quais foram os principais tipos e como os resultados evoluíram ao longo do tempo**.
